# TL;DR
 Claude Code 等 Agent 框架可以跨越三大作業系統（Windows、macOS 和 Linux），提供統一的程式開發和 DevOps 工作流程。

# 是什麼，為什麼現在才出現
 Claude Code 等 Agent 框架是一種跨平台的程式開發和 DevOps 工具，允許開發者在不同作業系統上執行相同的程式碼和工作流程。以前，開發者需要為每個作業系統單獨設定和安裝不同的工具和框架，現在 Claude Code 等 Agent 框架提供了一個統一的解決方案，讓開發者可以更容易地在不同平台上開發和部署程式。
