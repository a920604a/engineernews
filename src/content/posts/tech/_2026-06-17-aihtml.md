# TL;DR
使用 AI 寫 HTML 代碼來製作視頻，無需經驗也能輕鬆上手。

# 前置條件
* 基本的 HTML 知識
* 一台能夠運行瀏覽器的電腦
* 了解基本的 AI 概念（非必需）

# 步驟
### 步驟 1：選擇 AI 工具
目前市場上有許多 AI 工具可以幫助我們寫 HTML 代碼，例如：Google 的 AutoML、Microsoft 的 Azure Machine Learning 等。這裡我們以 Google 的 AutoML 為例。

### 步驟 2：安裝 AutoML 擴充套件
在 Google Chrome 瀏覽器中安裝 AutoML 擴充套件，然後重新啟動瀏覽器。

### 步驟 3：建立新專案
在 AutoML 中建立新的專案，選擇「HTML」作為專案類型。

### 步驟 4：設定專案參數
設定專案參數，包括：視頻長度、解析度、幀率等。

### 步驟 5：撰寫 HTML 代碼
使用 AutoML 提供的編輯器撰寫 HTML 代碼，AutoML 會自動幫助我們完成代碼。

### 步驟 6：預覽視頻
在 AutoML 中預覽視頻效果。

### 步驟 7：下載視頻
下載完成的視頻檔案。

# 完整範例
以下是一個簡單的 HTML 代碼範例，使用 AutoML 可以自動完成：
```html
<!-- AutoML 會自動幫助我們完成以下代碼 -->
<!DOCTYPE html>
<html>
<head>
  <title>我的視頻</title>
</head>
<body>
  <!-- AutoML 會自動插入視頻內容 -->
  <video width="640" height="480" controls>
    <source src="我的視頻.mp4" type="video/mp4">
    您的瀏覽器不支援視頻標籤。
  </video>
</body>
</html>
```
# 常見問題
* AutoML 不能自動完成所有的 HTML 代碼，需要手動修改部分代碼。
* AutoML 生成的代碼可能需要手動調整以適應不同的瀏覽器。
