做影片的門檻一直卡在工具上。After Effects 有學習曲線，Premiere 要對時間軸，CapCut 讓大家的內容都長一個樣。但如果你的影片主體是動態圖表、程式碼說明、或動態排版，其實有另一條路：讓 AI 幫你寫 HTML/JS 動畫，然後錄螢幕。

這個方法不適合所有影片，但對技術內容創作者來說非常實用。

## TL;DR

1. 用 Claude 或 ChatGPT 生成 HTML Canvas 或 CSS 動畫程式碼
2. 在瀏覽器裡跑起來
3. 用 OBS 或 QuickTime 錄螢幕
4. 做成影片

不需要任何影片剪輯軟體的知識。只要你看得懂基本的 HTML，就能做。

## 前置條件

- 一個 AI 工具（Claude、ChatGPT 或類似服務）
- 文字編輯器（VS Code 或任何能存 .html 的編輯器）
- 瀏覽器（Chrome 或 Firefox）
- 螢幕錄影工具（macOS 內建 QuickTime、Windows 的 Xbox Game Bar、或 OBS）

不需要安裝任何 npm 套件或框架——最簡單的版本只是一個 HTML 檔案。

## 核心概念：為什麼 HTML 動畫能取代影片

HTML Canvas 是瀏覽器原生的 2D 繪圖 API，可以做到：
- 逐幀動畫（用 `requestAnimationFrame`）
- SVG 路徑動畫
- CSS transition 和 keyframe animation
- WebGL（3D，進階用法）

這些東西在瀏覽器裡跑是「即時渲染」的，用螢幕錄影捕捉下來就是影片。品質取決於你的螢幕解析度，1440p 或 2160p 的螢幕錄下來的影片品質很夠用。

## 步驟

### 步驟 1：描述你想要的動畫

給 AI 一個具體的提示。越具體越好。以下是一個例子：

```
幫我寫一個 HTML 動畫，顯示一個排序演算法（Bubble Sort）的視覺化過程。
- 畫布大小：800 x 500
- 長條圖，30 根長條，隨機高度
- 比較中的長條用橘色，已排序的用綠色，其他用藍色
- 每次交換之間有 100ms 的延遲
- 動畫結束後顯示「排序完成」的文字
- 不要依賴任何外部套件
```

### 步驟 2：貼到 .html 檔案跑起來

AI 給你的程式碼通常是完整的 HTML，直接存成 `sort.html`，在瀏覽器打開就能跑。如果有錯誤，把錯誤訊息貼回給 AI 讓它修。

### 步驟 3：調整細節

常見需要手動調整的地方：
- 動畫速度（找到 delay 或 fps 相關的參數）
- 配色（直接在 CSS 或 Canvas 的 `fillStyle` 修改）
- 畫面尺寸（調整 canvas 的 `width` 和 `height`）

這些改動通常一目了然，不需要深入理解程式碼。

### 步驟 4：錄影

設定好瀏覽器視窗大小，開始錄螢幕，播放動畫，停止錄影。

**macOS：** Command + Shift + 5，選取視窗錄影  
**Windows：** Win + G 開啟 Xbox Game Bar  
**跨平台：** OBS Studio（免費，功能最完整）

### 步驟 5：後製（選填）

如果只是技術說明影片，有時候直接用錄下來的影片就夠。如果需要配音、字幕、或剪接，再用 DaVinci Resolve（免費版很夠用）或 CapCut 處理。

## 完整範例：動態文字出現效果

這個提示可以直接給 Claude 或 ChatGPT：

```
寫一個 HTML 動畫：
- 黑色背景，畫布 900x500
- 文字「Hello World」從左側滑入，白色大字（font-size: 72px）
- 接著文字逐個字母變成不同顏色（彩虹漸層）
- 最後文字縮放到 1.2 倍後回彈
- 整個動畫約 3 秒
- 動畫結束後停在最終狀態
```

AI 生成的程式碼會是完整可執行的 HTML，存檔打開就能看效果。

## 進階：Remotion 和 Motion Canvas

如果你想要更精確的控制，或要做長影片、需要程式化地組合多個場景，可以看看這兩個框架：

**Remotion** — 用 React 寫影片，可以直接在程式碼裡定義時間軸，輸出為真正的 MP4。適合需要精確控制每一幀的場景。

**Motion Canvas** — TypeScript 為主，設計給動態圖形和技術說明影片，有更豐富的動畫 API。3Blue1Brown 風格的數學動畫用這個很適合。

這兩個都需要 Node.js 環境，入門成本比「寫個 HTML 存檔」高，但給你的控制力也強很多。

## 常見問題

**Q: AI 生成的程式碼有 bug 怎麼辦？**  
把瀏覽器 console 的錯誤訊息複製，貼給 AI 說「這段程式碼出現了這個錯誤，幫我修」，通常一兩輪就能解決。

**Q: 動畫跑起來很卡怎麼辦？**  
要求 AI 「優化效能，減少不必要的重繪」，或把動畫的元素數量降低。也可以直接問 AI 「這個動畫為什麼卡，怎麼改善」。

**Q: 錄影的解析度不夠怎麼辦？**  
用 Retina/HiDPI 螢幕的話，可以告訴 AI 把 canvas 設定成 `devicePixelRatio` 的比例，讓輸出更清晰。
