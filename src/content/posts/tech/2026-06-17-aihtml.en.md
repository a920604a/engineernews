Video creation is often blocked by tooling. After Effects has a steep curve, Premiere requires working with timelines, and template-based apps make everything look identical. But if your video content is primarily animated diagrams, code walkthroughs, or dynamic typography, there's another path: have AI write HTML/JS animations, then record your screen.

This approach won't work for every video. For technical content creators, it's remarkably effective.

## TL;DR

1. Use Claude or ChatGPT to generate HTML Canvas or CSS animation code
2. Run it in the browser
3. Record your screen with OBS or QuickTime
4. Export as video

No video editing knowledge required. If you can read basic HTML, you can do this.

## Prerequisites

- An AI tool (Claude, ChatGPT, or similar)
- A text editor (VS Code or anything that saves .html)
- A browser
- A screen recorder (macOS QuickTime, Windows Xbox Game Bar, or OBS)

No npm, no frameworks required for the basics — just a single HTML file.

## Why This Works

HTML Canvas is the browser's native 2D drawing API. It can handle:
- Frame-by-frame animation via `requestAnimationFrame`
- SVG path animation
- CSS transitions and keyframe animations
- WebGL for 3D (advanced)

These run as real-time rendering in the browser. Screen recording captures them as video. Quality depends on your display resolution — a 1440p or 4K screen records at excellent quality.

## Steps

### Step 1: Write a specific prompt

Give the AI a concrete description. Vague prompts produce vague code.

Example:
```
Write an HTML animation that visualizes Bubble Sort.
- Canvas size: 800x500
- 30 bars with random heights
- Bars being compared: orange, sorted bars: green, default: blue
- 100ms delay between swaps
- Show "Sort Complete" text when done
- No external libraries
```

### Step 2: Save and open in browser

The AI output should be complete HTML — save it as `sort.html`, open in Chrome or Firefox. If there are errors, paste the browser console error back to the AI: "This error appeared, please fix it."

### Step 3: Adjust details

Common things to tweak:
- Animation speed (find the delay or fps parameter)
- Colors (CSS or Canvas `fillStyle` values)
- Canvas dimensions (`width` and `height` attributes)

These edits are usually obvious without understanding the whole codebase.

### Step 4: Record

Set your browser window size, start recording, play the animation, stop recording.

**macOS:** Command + Shift + 5, choose window recording  
**Windows:** Win + G (Xbox Game Bar)  
**Cross-platform:** OBS Studio (free, most capable)

### Step 5: Post-production (optional)

For pure technical explainers, the raw recording is often enough. If you need voiceover, captions, or cuts, DaVinci Resolve (free tier) or CapCut handles that.

## Example Prompt: Animated Text Reveal

Hand this directly to Claude or ChatGPT:

```
Write an HTML animation:
- Black background, canvas 900x500
- Text "Hello World" slides in from the left, white, font-size 72px
- Then each letter transitions to a different color (rainbow gradient)
- Finally the text scales up to 1.2x with a slight bounce back
- Total duration: ~3 seconds
- Ends frozen at the final state
```

The output should be runnable HTML — save and open to preview.

## Going Further: Remotion and Motion Canvas

For precise control, longer videos, or programmatically composing multiple scenes:

**Remotion** — Write videos in React. Define timelines in code, export to real MP4. Suited for when you need frame-accurate control.

**Motion Canvas** — TypeScript-first, designed for motion graphics and technical explainers. The API is richer than raw Canvas. Good for 3Blue1Brown-style math animations.

Both require a Node.js environment — higher entry cost than a single HTML file, but significantly more control.

## Troubleshooting

**Bug in generated code:** Copy the browser console error, paste it back to the AI: "This error appeared, please fix it."

**Animation running slow:** Ask the AI to "optimize performance and reduce unnecessary redraws," or reduce the number of elements.

**Recording resolution too low:** For Retina/HiDPI displays, ask the AI to scale the canvas by `devicePixelRatio` for crisper output.
