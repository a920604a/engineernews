# TL;DR

本文將教你如何應對飛機艙門關閉時因心理壓力導致的呼吸困難，提供三招急救法幫助你安全降落。

# 前置條件

* 基本的心理學知識
* 了解壓力反應的身體生理變化

# 步驟

### 步驟一：理解身體的警報器

當飛機艙門關閉時，身體會因為心理壓力而出現生理變化，如心跳加速、呼吸急促等。這些變化是身體的警報器失控的表現，表明大腦正在處理壓力和恐懼。了解這些變化是第一步。

### 步驟二：使用三招急救法

#### 1. 深呼吸

深呼吸可以幫助你放鬆身體，降低心跳速度。試著用鼻子吸氣，然後用嘴巴慢慢呼氣。重複這個過程，直到你感覺身體開始放鬆。

#### 2. 進行身體放鬆

緊張的身體會使呼吸變得困難。試著放鬆你的身體，從頭部開始，逐漸放鬆到腳部。這樣可以幫助你減少肌肉緊張，改善呼吸。

#### 3. 使用正念技巧

正念技巧可以幫助你專注於當下，減少對未來或過去的擔憂。試著關注你的呼吸，感受空氣進出你的身體。當你感覺到心跳加速或呼吸急促時，試著用正念技巧來平息它們。

### 步驟三：結合三招急救法

當你熟悉了三招急救法後，試著將它們結合起來使用。例如，你可以先進行深呼吸，然後進行身體放鬆，最後使用正念技巧來平息心跳和呼吸。

# 完整範例

以下是一個簡單的正念練習，你可以在飛機艙門關閉時使用：
```
我現在正在飛機上，我感到緊張和害怕。
我會用深呼吸來放鬆我的身體。
我會關注我的呼吸，感受空氣進出我的身體。
我會用正念技巧來平息我的心跳和呼吸。
```

# 常見地雷

* 如果你感覺到心跳加速、呼吸急促、出汗等症狀，可能是你正在經歷壓力反應。
* 如果你感覺到你正在專注於當下，減少對未來或過去的擔憂，你可能正在使用正念技巧。
