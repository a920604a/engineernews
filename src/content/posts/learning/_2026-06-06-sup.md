# 開始使用 Sup：簡單且高效的視訊會議工具

## TL;DR
Sup 是一款簡單易用的視訊會議工具，提供高質量的視訊通話體驗。

## 是什麼
Sup 是一款基於 WebRTC 的視訊會議工具，允許用戶進行點對點或多人視訊通話。它提供了簡單易用的界面，讓用戶可以快速地進行視訊會議。

## 為什麼重要
Sup 解決了傳統視訊會議工具的一些問題，例如複雜的設置過程和低質量的視訊通話體驗。Sup 的出現提供了一種簡單易用的視訊會議方式，讓用戶可以更方便地進行遠端溝通。

## 怎麼運作
Sup 的運作原理如下：

```mermaid
graph LR
    A[用戶] -->|點擊連結|> B[Sup 伺服器]
    B -->|建立連線|> C[WebRTC 伺服器]
    C -->|建立通話|> D[其他用戶]
    D -->|傳輸視訊|> C
    C -->|傳輸視訊|> B
    B -->|傳輸視訊|> A
```

## 跟其他視訊會議工具的差別
相比其他視訊會議工具，Sup 的優勢在於其簡單易用的界面和高質量的視訊通話體驗。Sup 不需要用戶進行複雜的設置過程，就可以快速地進行視訊會議。

## 小結
Sup 適合需要進行簡單易用的視訊會議的用戶，特別是那些需要遠端溝通的團隊或個別用戶。Sup 的高質量視訊通話體驗和簡單易用的界面，使其成為了一種理想的視訊會議工具。
