做影片這件事，門檻一直卡在工具上。After Effects 有學習曲線，Premiere 要對時間軸，CapCut 讓大家的影片都長一個樣。但如果你做的是技術內容——動態圖表、排序演算法視覺化、程式碼說明——其實有一條更省力的路。

讓 AI 幫你寫 HTML 動畫，在瀏覽器跑起來，然後錄螢幕。就這樣。

聽起來很土，但它真的夠用。瀏覽器的 Canvas API 是原生的 2D 繪圖引擎，可以做逐幀動畫、CSS 過渡效果、甚至 WebGL 的 3D 場景。這些都是即時渲染，用螢幕錄影捕捉下來就是影片。如果你的螢幕是 1440p 或 4K，品質完全堪用。

流程只有四步。第一步，給 AI 一個具體的提示。越具體越好——比如「幫我寫一個 Bubble Sort 視覺化動畫，畫布 800x500，三十根長條，比較中的長條用橘色，已排序的用綠色，每次交換間隔 100 毫秒，不要用任何外部套件」。重點是把所有細節說清楚：尺寸、顏色、時間、還有最後那句「不要外部套件」——這樣 AI 給你的就是單一 HTML 檔，存下來直接打開就能跑。

第二步，把 AI 給你的程式碼存成一個 `.html` 檔，在瀏覽器打開。如果有錯誤，把瀏覽器 console 的錯誤訊息複製，貼回去給 AI 說「幫我修」，通常一兩輪就解決了。

第三步，微調細節。動畫速度、顏色、畫面尺寸，這些在程式碼裡都很好找，通常改個數字就夠。不需要深入理解整個程式怎麼運作。

第四步，錄螢幕。macOS 用 Command + Shift + 5，可以選單一視窗錄影。Windows 有內建的 Xbox Game Bar。跨平台的話，OBS Studio 免費而且功能最齊全。設定好視窗大小，開始錄，播完動畫，停止錄影。

如果只是技術說明，錄下來的影片可以直接用。需要配音或字幕再開 DaVinci Resolve 的免費版處理。

當然，這個方法有它的侷限。它適合技術動畫、圖表、排版效果，不適合真人出鏡或複雜的剪輯場景。如果你需要更強的控制力，有兩個框架值得了解：Remotion 讓你用 React 寫影片，可以精確控制每一幀然後輸出真正的 MP4；Motion Canvas 是 TypeScript 為主，特別適合 3Blue1Brown 那種風格的數學動畫。兩個都需要 Node.js 環境，入門成本比「存個 HTML 檔」高不少，但也給你相應更強的能力。

收攏一下這個方法的核心：第一，前置成本幾乎是零，不需要安裝任何套件，一個瀏覽器和一個文字編輯器就夠。第二，AI 幫你填補了「我不會寫動畫」的能力缺口，你只需要能看懂基本 HTML 結構，知道去哪裡改數字。第三，這個方法最大的甜蜜點是技術內容——如果你在做程式教學、架構說明、或任何「需要動起來才說得清楚」的東西，這條路比開影片軟體省掉的時間相當可觀。
