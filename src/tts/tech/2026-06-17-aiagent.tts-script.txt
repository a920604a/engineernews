影片製作一直是個高門檻的事情。要會剪輯、要有素材、還要錄旁白——光是做一支三分鐘的說明影片，搞不好就要花掉你半天。但如果有一個 Agent，你只要丟一個主題進去，它自動幫你寫腳本、配音、生成畫面、然後剪成完整影片呢？這件事現在真的可以做到，而且完全不用寫程式。

核心概念是把四個東西串在一起：LLM 負責生成腳本，TTS 負責把文字轉成語音，影片生成 API 負責製作畫面素材，最後用 FFmpeg 把音頻和視頻合併起來。串接它們的平台，用的是 n8n——一個開源的自動化工具，就像 Zapier 但可以自己架，而且更靈活。

這整條流程是典型的 Agent 工具鏈——每個步驟的輸出就是下一步的輸入。LLM 先把主題轉成結構化腳本，分成幾個段落，每段有旁白文字和對應的畫面描述。接著 TTS 拿旁白文字生成 MP3，影片生成 API 拿畫面描述生成片段，最後 FFmpeg 把兩個合在一起。

工具怎麼選？腳本用 Claude 3.5 Sonnet 或 GPT-4o，讓它輸出 JSON 格式，方便後面流程處理。語音合成的話，ElevenLabs 音質最自然，有免費額度可以試；Azure AI Speech 繁體中文支援很好，適合正式場景；如果只是本地測試，Edge TTS 完全免費，音質也夠用。影片素材生成，Runway Gen-3 品質高，Pika 操作簡單，HeyGen 則是做 AI 虛擬人物主播的。

n8n 的流程設定大概長這樣：先建一個 Webhook 節點當入口，可以接 Slack 訊息或表單。接著用 HTTP Request 節點打 Claude 的 API，拿回 JSON 格式的腳本。然後拆分每個段落，用 Split In Batches 逐段處理——先打 ElevenLabs 生成 MP3，再打 Runway 生成影片片段，最後用 Execute Command 節點呼叫 FFmpeg 合併。整個流程設好之後，以後每次觸發 Webhook，幾分鐘就能出影片。

這裡最關鍵的一步是設計給 LLM 的 Prompt。格式要嚴格，讓它輸出 JSON，包含影片標題和每個段落的旁白文字加畫面描述。特別要注意的是，畫面描述要用英文——Runway、Pika 這些工具對英文描述的理解效果明顯比中文好。

跟傳統流程比起來差距很明顯。寫腳本原本要三十到六十分鐘，LLM 三十秒就搞定。配音原本要錄音室或外包，TTS 即時生成。素材原本要買素材庫或自己拍，現在 AI 生成。剪輯原本要手動操作剪輯軟體，現在 FFmpeg 自動合併。整個流程從原本的半天到幾天，壓縮到五到十五分鐘。

當然也有明顯的限制要說清楚。費用方面，Runway 按秒計費，長影片成本可觀，要先算好預算。生成時間也不快，每個片段要一到三分鐘，整條流程跑下來可能二十分鐘。畫面一致性是另一個問題，不同段落 AI 生成的畫面風格可能不統一，要在 Prompt 裡特別強調保持風格一致。n8n 的話建議用 Docker 自架，流程資料不要過雲端服務。

這套 Agent 最適合做大量重複性內容，像是產品介紹、教學影片、新聞摘要，或是需要快速跑出多個語言版本的場景。但如果你的內容需要真人情感連結，比如訪談或個人品牌影片，或者對畫面精準度要求很高的商業廣告，現階段 AI 生成素材的穩定性還撐不起來，這部分還是得人工介入。

總結三個重點。第一，這套系統的本質是 Agent Tool Chain，LLM 協調多個 AI 工具，每個工具各司其職。第二，n8n 讓你不用寫程式就能把這些 API 串起來，關鍵是 Prompt 設計要讓 LLM 輸出嚴格的 JSON 格式。第三，現在最大的瓶頸不是技術，是成本和畫面一致性——做之前先用免費額度跑通整條流程，再考慮規模化。
