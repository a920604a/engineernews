AI coding agent 這個詞，一年前聽起來還有點炫技的感覺，但現在它已經是很多工程師日常工作流的一部分了。OpenAI 的 Codex CLI、Anthropic 的 Claude Code、GitHub Copilot 的 agent 模式，這些工具都在快速演化。今天要聊的是：怎麼用最少的錢，甚至不花錢，把這些工具的價值榨到最大。

先把核心策略說清楚。第一，弄懂每個工具的計費邏輯，因為不同工具的計費單位差很多，有的按請求次數、有的按 token、有的按時間。第二，不同複雜度的任務派給不同工具，不要用大砲打蚊子。第三，自架開源模型作為補充。這三個原則貫穿整個策略。

來逐一看主要工具。

**Codex CLI** 是 OpenAI 的終端機 AI coding agent，可以讀你的程式碼庫、執行指令、修改檔案。工具本身開源免費，但背後的 API 呼叫要付錢。新用戶有大約五美元的試用額度，用完就要付費了。不過有個技巧：可以在設定裡把模型切換成 `gpt-4o-mini` 或 `o3-mini`，費用會便宜非常多，大多數中等任務用這些模型就夠了。

**Claude Code** 的情況不太一樣，它需要付費方案才能跑。但如果你只是想試試感覺，`claude.ai` 的網頁版是免費的，雖然沒有完整的 agent 模式，但用來做一次性的大任務、設計系統架構、分析複雜問題，其實很值得，因為你省下的是 API 費用。

**GitHub Copilot** 有個免費方案，每個月給兩千次自動補全和五十次 chat 請求。對於日常的程式碼補全，這個量通常夠用。但要注意，agent 模式需要付費方案，免費版只有補全和基本 chat。

然後是完全不花錢的選項。**Ollama 加上本機模型**是最直接的方案——在自己機器上跑開源模型，沒有額度限制。搭配 **Continue.dev** 這個 VS Code 擴充套件，可以把本機跑的模型接進去作為 AI 助手。DeepSeek Coder 是目前 coding 任務表現比較好的開源選項。代價是你需要足夠的硬體：七 B 的模型至少要八 GB 的顯存，十六 B 要十六 GB。沒有獨立顯卡也可以跑 CPU 模式，但速度會慢很多。

**Cline**，前身叫 Claude Dev，是 VS Code 的開源 agent 套件，可以接任何 OpenAI 相容的 API，包括 Ollama 的本機模型，彈性很高。

說到最大化免費額度，最關鍵的一個習慣是：**明確告訴 agent 要看哪些檔案**。很多人習慣丟一個模糊的問題讓 agent 自己判斷，但這樣它可能會把整個程式碼庫塞進 context，token 就這樣燒掉了。如果你明確指定相關的兩三個檔案，token 消耗可以大幅下降。

整個工作流的思路是這樣：日常的程式碼補全，用 Copilot 免費版就夠了；快速的一次性問題，用 claude.ai 網頁版；中等複雜的重構或寫測試，用 gpt-4o-mini 這種便宜模型；複雜的架構設計或難解的 bug，才動用強模型或存起來的 credit；批量的簡單任務，用本機 Ollama 跑。

最後關於 DeepSeek API 值得單獨提一下：它的定價比 OpenAI 便宜很多，而 DeepSeek-V3 在程式碼任務的表現已經接近 GPT-4o，如果你需要用 API 跑一些量，這是很值得考慮的替代。

好，總結三個重點帶走。一，免費不代表沒用，關鍵是理解每個工具的計費邊界，在邊界內把它用到極致。二，任務分層是省錢的核心，不要什麼事都找最強模型，簡單的任務用便宜工具，複雜的才動用昂貴資源。三，本機自架模型是真正意義上的無限免費，硬體門檻有，但一旦跨過去，批量任務完全不用花錢。這套組合拳打好，大多數工程師的日常開發需求，免費或接近免費是可以做到的。
