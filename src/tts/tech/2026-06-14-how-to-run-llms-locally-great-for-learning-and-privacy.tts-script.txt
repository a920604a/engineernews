今天來聊一個很多人覺得門檻高、但其實超簡單的事——在自己電腦上跑 LLM。

為什麼要在本機跑？三個理由。第一是隱私，敏感資料不需要送出去。第二是學習，你可以直接摸模型的真實行為，不是隔著 API 看個黑盒子。第三是成本，硬體一次投入，後續不用付 token 費。

工具的部分，現在生態已經很成熟，Ollama 是目前最好上手的本地 LLM runtime，沒有之一。

先說硬體門檻。八 GB RAM 可以跑 3B 到 7B 的量化模型，流暢度還不錯。十六 GB 可以跑到 8B，體驗更好。三十二 GB 以上，14B 的模型就跑得很順。沒有 GPU 也可以跑，只是速度會慢一點——有 GPU 的話，不管是 NVIDIA、Apple Silicon，還是 AMD，Ollama 都會自動偵測，速度大概快個十到五十倍。

安裝的部分超簡單。macOS 或 Linux 一行指令搞定，Windows 的話去官網下載安裝包。裝完跑個版本確認，看到版本號就代表成功了。

接下來下載模型。要快速測試的話，拉 Llama 3.2 的 3B 版本，大概兩 GB 左右。想要品質好一點，拉 8B 版本，約五 GB。如果你需要中文能力，Qwen 2.5 7B 是目前繁體中文表現最好的選項之一。下載完直接在 terminal 裡就可以開始對話，輸入 `/bye` 或按 Ctrl+D 退出。

然後是最實用的部分——REST API 整合。Ollama 啟動之後，會在本機的 11434 port 提供一個跟 OpenAI 完全相容的 API。這代表什麼？你原本用 OpenAI API 寫的程式，只要把 base URL 改成指向 localhost，完全不用改其他程式碼，就能切換到本地模型。這個設計非常聰明，降低了遷移成本。

常見的模型選擇，簡單說幾個：Llama 3.2 3B 適合快速測試、硬體需求低；8B 版本 CP 值很高；Qwen 2.5 7B 中文能力比較好；Mistral 7B 英文推理跟程式碼表現不錯；CodeLlama 7B 專門做程式碼生成；還有一個比較特別的，nomic-embed-text，大小只有三百 MB 左右，是做文字嵌入用的，如果你要在本機做 RAG，這個是首選。

講到 RAG，Ollama 可以讓你做完全離線的 RAG pipeline。做法是用 nomic-embed-text 把你的文件轉成向量，查詢的時候計算餘弦相似度找出最相關的文件，然後把這個文件塞進 prompt 讓 Llama 生成回答。整個流程不需要任何外部 API，完全跑在本機。

幾個常見問題快速過一下。跑很慢的話，先確認 Ollama 有沒有用到 GPU，跑 `ollama ps` 看一下 GPU 欄位。中文輸出亂碼，通常是因為量化版本精度不夠，可以換 Qwen 2.5 系列，繁體中文支援比較好。多人共用一台 Ollama server 是可以的，它支援多個 concurrent request，但 GPU 記憶體是共用的，同時跑太多大模型要注意記憶體。

好，總結三個核心重點。

第一，本機跑 LLM 的門檻比你想的低，八 GB RAM 就夠起步，Ollama 一行安裝。

第二，Ollama 的 API 完全相容 OpenAI，切換成本幾乎是零，只改一行 base URL。

第三，結合 embedding 模型，你可以做完全離線的 RAG，適合隱私敏感的場景。

如果你一直覺得本地 LLM 很複雜、門檻很高，現在是最好的時機試試看。
